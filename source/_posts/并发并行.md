**并发与并行**
并发指计算机能够同时执行多项任务
- 单核处理器：在不同任务之间进行切换实现并发
- 多核处理器：让任务运行在不同芯片上真正实现并发（也就是**并行**）

**同步与异步**
两种不同的编程模型
- 同步：前一个任务执行完之后才能执行下一步，没有并发和并行的概念
- 异步：不同任务之间不会相互等待，同时执行
    - 异步的实现方式：多线程真正并发
    - 单线程通过回调函数实现并发

**单线程与多线程**
单线程
- 适用范围：需要执行大量IO操作的网页应用
- 好处：可以不让IO阻塞程序，同时可以避免多线程带来的诸多问题

**javascript中的异步操作**
Promise, async, await的概念阐述

**Promise函数**
当进行一些需要等待的IO操作时，函数调用会立马返回一个Promise函数
接着，就可以调用Promise函数的.then()方法，并传递一个匿名函数，告诉函数得到结果后运行这个匿名函数
代码模板：
```
fetch('xxx.com').then((response) => { ... });
```
同时可以链式调用，也就是将多个then串起来，提高代码可读性
```
fetch('xxx.com')
.then((response) => { ... })
.then(...)
.then(...);
```
若在运行过程中，任意一个then里的函数抛出了错误，都可以适用catch抓住。
还有finally函数，用于收尾工作
```
fetch('xxx.com')
.then((response) => { ... })
.catch((error) => { ... })
.finally(() => {...})
```

**async，await关键字**
可以使用async将一个函数定义为异步函数，并在其中某些需要等待异步操作完成返回promise的函数之前加上await关键字
这样函数就变成了同步，会等待并顺序执行
```
async function f(){
    const PromiseA = await fetch('xxx.com');
    const PromiseB = await fetch('yyy.com');
}
```
这样，只有PromiseA执行完之后拿到结果后才会执行PromiseB
最后，注意：await关键字只能使用在异步async函数中
